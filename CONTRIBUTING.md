# Contributing

Thank you for helping improve Smart Route for the security and developer communities.

## Getting started

1. Fork the repository  
2. `flutter pub get`  
3. Create a branch: `git checkout -b feature/your-change`  
4. Run tests: `flutter test`  
5. Open a pull request with a clear description  

## Code guidelines

- Match existing Dart/Kotlin style  
- Keep mock injection logic in `MockLocationEngine` / `MockLocationForegroundService`  
- Document new permissions in README and AndroidManifest  
- Do not add features intended solely for harassment or fraud  

## Pull request checklist

- [ ] `flutter analyze` passes  
- [ ] `flutter test` passes  
- [ ] README updated if behavior or setup changes  
- [ ] No secrets (API keys) committed
